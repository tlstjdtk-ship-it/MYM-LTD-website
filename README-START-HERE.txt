MYM-LTD V5 / 시작 안내

1) Windows 7: 압축을 풀고 index.html을 더블클릭하면 기존 사이트 및 데일리 리포트 영역을 확인할 수 있습니다.
2) 최초 리포트는 '데이터 대기'가 정상입니다. 임의의 시세는 넣지 않았습니다.
3) 실제 자동 업데이트: GitHub에 이 폴더의 모든 파일(숨김 .github 폴더 포함)을 올리고 GitHub Pages Source를 GitHub Actions로 지정합니다.
4) Actions 탭에서 'MYM daily market report and site deploy'를 한 번 수동 실행하세요.
5) 예약 시간: 한국시간 화~토 오전 7:20 (미국 월~금 거래일 마감 후). 공휴일에는 직전 거래일 데이터가 유지될 수 있습니다.
6) 데이터 출처: Stooq 무료 일별 ETF CSV. 소스 차단, 지연, 서비스 약관 변경 가능. 공개 상업 사이트 배포 전 데이터 라이선스 확인 필요.
7) 공식 지수 대신 SPY/QQQ/DIA/IWM ETF를 사용하며, 리포트는 투자 조언이 아닙니다.
8) GitHub Actions 예약 실행은 지연/누락될 수 있고, 공개 저장소는 60일 비활동 시 스케줄이 중단될 수 있습니다.
9) 무료 GitHub Pages 공개 저장소에는 사이트 소스와 보고서가 공개됩니다. 개인 API 키, 거래 기록, 비밀정보는 절대 올리지 마세요.
10) 오류 시 마지막으로 성공한 리포트를 유지하되 화면의 데이터 기준일을 반드시 확인하세요.
